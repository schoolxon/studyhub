## 2. Pehla hire kaun (sabse important decision)

**Agar tum technical ho** → pehla hire **sales/onboarding** karo, developer nahi.
Product tum bana loge, par 50 libraries me ghoomna aur onboarding karna alone nahi hoga.

**Agar tum non-technical ho** → pehla hire ek **strong full-stack dev** (ya technical
co-founder). Agency mat lena — SaaS me har hafte change chahiye hota hai, agency
model isme fail hota hai.

---

## 3. Sales executive ka profile (India specific)

Ye role sabse under-rated hai. Dhoondo:
- Hindi + local language fluent
- Field sales ka experience (insurance, FMCG, coaching sales — koi bhi)
- Bike/scooter ho (roz 5-8 libraries visit karni hain)
- Smartphone comfortable
- Degree matter nahi karti, attitude karta hai

**Compensation:** ₹20,000 fixed + ₹500 per conversion + ₹200 per activated trial
Achha performer ₹35-45k bana lega, aur ye profitable rahega (CAC ₹1,200 tak theek hai).

**Onboarding:** pehle 2 hafte tumhare saath ghoome, tum demo do wo dekhe.
Phir wo de, tum dekho. Phir akela.

## 4. Hiring process

### Developer ke liye
1. Resume screen — GitHub dekho, resume nahi
2. **Paid take-home task** (₹2,000-5,000, 4-6 ghante ka):
   > "Ek REST API banao jo multi-tenant hai. Ek `bookings` resource — same room,
   > same time slot pe double booking nahi honi chahiye. Tests likho.
   > README me batao ki race condition kaise handle ki."
   Ye exact task tumhare product ka core problem hai — jo isse solve kar le wo fit hai.
3. Code review discussion (1 hour) — kyun kiya, aur kaise karte
4. Culture fit — startup me kaam kiya hai? Ownership lene ka mann hai?

### Sales ke liye
1. Phone call — kaise pitch karega, sunke pata chal jayega
2. **Field test:** "Kal 5 libraries visit karo, ye brochure leke jao, feedback lao"
   (₹500 do). Jo actually ja aaye wo hire karo.

## 7. Culture rules (chhoti team ke liye)

1. **Har koi customer se baat kare** — developer bhi mahine me 2 library visit kare
2. **Ship daily** — chhota feature roz, bada release mahine me
3. **Bug > feature** — customer ka bug pehle, naya feature baad me
4. **Support ticket sab dekhein** — shared WhatsApp/Slack channel
5. **Har churn pe post-mortem** — kyun gaya, kya kar sakte the
