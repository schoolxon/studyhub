# 21 — First 30 Days: Kal Se Kya Karna Hai

Agar aaj se shuru karna hai to ye exact checklist follow karo.

## Week 1 — Zameen pe utro
- [ ] **Day 1:** 30 libraries ki list banao (Google Maps + Instagram), spreadsheet me
- [ ] **Day 2:** 3 libraries visit karo. Kuch bechna nahi hai — sirf sawaal poocho aur
      unka register dekho. Photo lo.
- [ ] **Day 3:** 3 aur visit. Ab tak pattern dikhne lagega.
- [ ] **Day 4:** 4 aur visit. Total 10 ho gaye.
- [ ] **Day 5:** Notes analyze karo. Top 5 pain points likho. Kitne paise dene ko tayyar
      hain, note karo.
- [ ] **Day 6:** 2-3 competitor software ka trial lo, screenshots lo, kamiyan list karo.
- [ ] **Day 7:** **DECISION:** 6/10 log ₹500+ dene ko tayyar hain? Haan → aage.
      Nahi → positioning badlo.

## Week 2 — Setup
- [ ] **Day 8:** Domain kharido, GitHub repo, Cloudflare setup
- [ ] **Day 9:** **DLT registration submit karo** (TRAI portal) — ye sabse lamba lagta hai
- [ ] **Day 10:** WhatsApp BSP account (AiSensy/Interakt) + Razorpay KYC submit
- [ ] **Day 11:** MVP feature list lock karo (`02-Complete-Feature-Specification.md`
      ka P0 section edit karo apni research se)
- [ ] **Day 12:** 10 core screens design karo (Figma ya direct shadcn)
- [ ] **Day 13:** Dev environment: Docker Compose, Postgres, **new** `apps/api` scaffold
      (Vite+Firebase ko evolve mat karo)
- [ ] **Day 14:** `12-Sprint-Task-Checklist.md` ko Notion/Linear me import karo

## Week 3 — Foundation code
- [ ] Auth + OTP + JWT
- [ ] Multi-tenancy: FORCE RLS + `set_config` **inside** `$transaction` + isolation test
- [ ] `platform_admins` table (super admin `users.tenant_id` NULL nahi)
- [ ] Basic layout + login screens
- [ ] CI pipeline
- [ ] **Beech me:** 5 libraries visit, 5 pilot commitments (6 months free)

## Week 4 — Setup module
- [ ] Branches (`code` field), shifts, seats, fee plans
- [ ] Setup wizard
- [ ] Seat map component
- [ ] **Beech me:** ek pilot owner ko seat map dikhao, feedback lo

---

## Har hafte ye 3 cheezein zaroor karo (chahe kuch bhi ho)

1. **Kam se kam 3 library owners se baat** — phone ya visit
2. **Kuch ship karo** — chhota bhi chalega, par staging pe deploy ho
3. **Ek metric track karo** — pilot libraries ka daily login

---

## 30 din ke baad ka reality check

| Sawaal | Agar jawab "nahi" hai to... |
|---|---|
| 10+ owners se baat ki? | Sales sabse bada risk hai, abhi shuru karo |
| 5 pilot commit hue? | Product-market fit ka sawaal hai, positioning badlo |
| DLT/WhatsApp/Razorpay applications submit hain? | Launch 3 hafte late hoga |
| Auth + tenancy + seat map chal raha hai? | Scope chhota karo, timeline realistic karo |
| Roz code + weekly customer contact ka balance hai? | Ek din customer ke liye block karo |

---

## Sabse bada advice

> 16–20 weeks me register-replacement banao, 5 libraries me daal do. Perfect mat
> banao. Wo tumhe batayengi ki asli product kya hai. `19` ke 5–6 months (solo)
> yahi hai — `00` ka purana 10-week line 2-dev case tha.
>
> Jo cheez tum abhi soch rahe ho ki "ye zaroori hai" — 60% wo galat hoga.
> Sirf customer bata sakta hai kaunsa 40% sahi hai.
